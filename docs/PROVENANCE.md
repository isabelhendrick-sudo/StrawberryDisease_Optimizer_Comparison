# Research files and provenance

| Asset | Source |
| --- | --- |
| Primary small-CNN run metrics | The November project export named `results(1).csv`, preserved as `docs/results/smallcnn-224/results.csv`. The CSV has 20 runs. The November report identifies this run as 224 × 224. |
| Primary small-CNN validation sweep | Table 4 of the November report, transcribed at the report's precision. The repository includes the table and the trainer for rerunning the sweep. |
| Primary summary figure | Generated from the November small-CNN run CSV and the original ResNet-18 run CSV using `scripts/plot_primary_results.py`. |
| Archived 128 × 128 small-CNN runs | The synced project’s `roboflow_resnet/runs/final` directory. The selected learning rates differ from those for the primary 224 × 224 runs. |
| ResNet-18 training, sweep and analysis | The synced project's `roboflow_resnet/runs_resnet18` directory. The final CSV records the model, input size, CUDA device and validation target. |
| ResNet-18 figures | The original figures from the synced project's `roboflow_resnet/figures_resnet18` directory. |
| Archived figures | The earlier `StrawDisease_Optimizer_Comparison` folder. Its October figures document the earlier 128 × 128 baseline and its comparison to ResNet-18. |
| Preprocessing counts | The synced project's `roboflow_resnet/strawberry_cls/summary.txt`. The cleaner regenerates the crop manifest. |
| Training and analysis code | The `roboflow_resnet` scripts and the earlier repository's cleaner. The unified trainer supports both the small CNN and ResNet-18. |

The November report is the source for the published timing correction and CPU-step benchmark. The recorded SGD seed-0 wall-clock time remains intact in the primary CSV. Epochs-to-target are taken directly from the CSV. The September pilot, AI Hub blight/wilt experiments, and unrelated notebooks are outside this repository's three-class study.

The November small-CNN histories and per-image predictions were unavailable in the synced project folder. The small-CNN training curves and confusion matrices under `docs/figures/smallcnn/` are for the earlier 128 × 128 experiment. This repository includes run-level metrics and aggregate analysis. Epoch histories and per-image predictions can be generated by rerunning training.

The original dataset export reports 4,918 images, and the cleaning log records 4,898 scanned. The study materials give no reason for the difference. The full image dataset and trained weights can be obtained by downloading the source export and running the local preprocessing and training commands. Dataset licensing follows the upstream Roboflow listing. No separate project code license has been assigned.
